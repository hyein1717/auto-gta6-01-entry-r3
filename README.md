**Ember Bay** — an original 3D open-world bay-city crime game built with three.js. Play as Rey Salmar, a driver in the sunset city of Ember Bay: drive or walk the streets, weave through traffic and pedestrians, and run fixer Madame Ora's three chained missions — a timed package run, a gold-car theft, and a three-star getaway to the lighthouse — while the police wanted system (0–5 stars) hunts you down. Features a live minimap, cash/health HUD, repeatable paid errands, synthesized WebAudio engine/siren sounds, and localStorage progress saves. Fully offline; the three.js engine is vendored in the repo.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in a browser
```
